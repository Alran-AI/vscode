# Install the Alran CLI

The extension does not bundle the agent. It starts `alran acp` from the CLI on your machine.

```sh
curl -fsSL https://cdn.ottili.one/public/install.sh | bash
```

On Windows, run `irm https://cdn.ottili.one/public/install.ps1 | iex` in PowerShell. If the CLI is somewhere unusual, set **Alran: Executable Path** in Settings.
