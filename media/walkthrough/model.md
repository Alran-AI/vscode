# Pick a model

| Model | Input / output per 1M tokens | Billed by |
| --- | --- | --- |
| Ottili Werk 1.1 (default) | $0.50 / $1.50 | Ottili: welcome or purchased credit |
| Claude Sonnet 5.5 | $2.00 / $10.00 (Anthropic's price) | Anthropic, on your own API key |
| Claude Opus 5.5 | $4.00 / $20.00 (Anthropic's price) | Anthropic, on your own API key |

Claude runs on **your own Anthropic API key** — add it once with **Alran: Add or Replace Your Anthropic Key**. Anthropic bills you directly; Ottili charges nothing for Claude.

**Alran: Choose Model** (`Ctrl+Alt+M`, `Cmd+Alt+M` on macOS) switches the model of the current session. The star button in the list makes a model the default for new sessions.
