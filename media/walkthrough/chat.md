# Run your first task

Open the Alran panel in the activity bar and describe a task.

- `@` adds files and Plugins, `Ctrl+Alt+L` adds the selection
- `/` lists commands and Skills
- `Shift+Tab` toggles Plan Mode, `Alt+M` the permission mode
- `Enter` steers a running task, `Ctrl+Enter` queues the next one, `Esc` stops

In VS Code you can also type `@alran` in the Chat view.
