# Add Plugins and Skills

The **Plugin Store** and the **Skill Library** are built in.

- **Plugins** are packages of Skills, MCP servers, connectors and hooks.
- **Skills** are single instructions the agent loads when they fit the task.

Type to search, press **Enter** to install, and use the buttons on a row for details, to switch a Plugin on or off, or to remove it. The title bar switches between *Plugins*, *Skill Library*, *Installed* and *Stores*.

A Plugin that runs commands is shown to you first, with every command it would run, and is installed only after you approve. Every download is verified against the store's index.

Skills and Plugins load when a chat starts, so open a **New Chat** afterwards. `/plugin` and `/skills library` open the same view from the chat.
